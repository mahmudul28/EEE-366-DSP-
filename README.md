# EEE-366: Digital Signal Processing Sessional

This repository contains all the lab experiments, assignments, and source code developed for the EEE-366 curriculum. 

## Tools & Software
Digital Signal Processing concepts are explored & implemented using two primary environments:
* **Python:** Lab experiments implemented via Jupyter Notebooks (`.ipynb`), utilizing core libraries such as `numpy`, `matplotlib`, and `scipy`.
* **MATLAB:** Scripts and functions (`.m` files) used for signal generation, system analysis & filter design.
